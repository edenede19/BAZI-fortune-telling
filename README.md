# 八字全书

资料最全的四柱八字 skill。经典原文可检索，句句配白话注释，排盘之后按命例逐步详解。

学八字最难的不是找不到书，而是书在不同体系里：有人讲格局，有人讲旺衰，有人讲调候，古法还夹着纳音和神煞。八字全书把这些收进同一个 skill——该读的经典都在，原文能核对再用精确排盘把理论落到具体命例上。



同一套流程里贯通了子平命理最该对照的几部经典：

- 《滴天髓》：全文与原注，另有逐句白话
- 《穷通宝鉴》：原书正文，加上十干 × 十二月调候白话总表
- 《渊海子平》：导读，以及《继善篇》原文白话
- 《三命通会》：全书结构与核心观点的白话导读
- 《五行精纪》：全文，以及六十甲子纳音白话表
- 《兰台妙选》：原文与旧注，以及取象白话
- 《千里命稿》：方法归纳（因版权保护，不收录原文）

此外还有精确排盘脚本、13 篇白话解读指南，以及可检索的公有领域典籍原文库。受版权保护的现代评注和近人著作，只转述方法，不录原文。

白话注释，案例详解

指南不是把古文再抄一遍，而是写成能直接用于断命的白话。分析命盘时，按十步论命流程做案例详解：先排盘，再看日主与季节、旺衰、格局、用神，然后论性情、事业、六亲与大运流年。关键论断都会引出原文，并附上白话。

IE：1993 年 6 月 18 日上午 10 点，男，辽宁丹东

| | 年柱 | 月柱 | 日柱 | 时柱 |
|---|---|---|---|---|
| 十神 | 伤官 | 偏印 | 日主 | 劫财 |
| 天干 | 癸 | 戊 | 庚 | 辛 |
| 地支 | 酉 | 午 | 午 | 巳 |

五月午月，日主庚金。月令为火，庚金失令；但年支酉通根，时支巳中藏庚，天干又有戊土偏印、辛金劫财，同党仍有力，不宜从弱。地支午午自刑、巳酉半合金，天干戊癸合。

> 《滴天髓》云：「庚金带煞，刚健为最。得水而清，得火而锐。」白话：庚是刀剑之金，最刚健；见水则锋芒被泄而清秀，见火则锻炼成器而锋利。

《穷通宝鉴》五月庚金专用壬水，癸水次之。此造年干透癸，可泄火金之锐，但地支午午巳火气偏旺，仍喜水运制火。当前乙卯大运（2017—2026）正财当令，乙合庚、卯冲酉：财星来合，机会多，却也冲了金之根，宜借力而行。2026 丙午年，丙火七杀合时干辛，午火与月、日自刑，岁运木火相生，工作压力会偏大，宜以印化杀；健康方面以体检为准。

这只是用法示例。完整解读还会校正节气与真太阳时，并按人生经历回看应期。

## 排盘能算出什么

`scripts/calculate_bazi.py`（基于 `lunar_python`）负责精确排盘，不要靠模型心算日柱和节气。输出包括：

四柱、十神、藏干、十二长生（星运 / 自坐）、纳音、旬空、胎元、命宫、身宫；真太阳时（常用城市经度，或直接给经度）；节气交接提示与月令人元司令；五行计数、加权与占比；得令、得地、得势；天干合冲，地支六合、三合、半合、拱合、三会、冲、刑、害、破；三十余种神煞；起运精确到年月日；大运、流年及其与原局、大运的刑冲合会。支持 Markdown 与 JSON 输出；时辰不详可排三柱。

`scripts/generate_html.py` 可生成暗色主题的可视化命盘。

## 安装

### Claude Code

```bash
git clone https://github.com/edenede19/CYBEREDEN-BAZI-fortune-telling.git ~/.claude/skills/bazi-quanshu
pip install -r ~/.claude/skills/bazi-quanshu/requirements.txt
```

### Claude.ai / Claude 桌面版

设置 → Capabilities/Skills → 上传本仓库打包后的 `.skill` 或 zip。

### 其他智能体

把整个目录放到该智能体的 skills 目录。入口是 `SKILL.md`，脚本需要 Python 3.8+ 与 `lunar_python`。

## 快速测试

```bash
pip install lunar_python
python3 scripts/calculate_bazi.py --solar 1993-6-18 --hour 10:00 --gender 男 --city 丹东 --format md
```

然后对助手说：「帮我看看八字，1993 年 6 月 18 日上午 10 点，男，辽宁丹东。」
