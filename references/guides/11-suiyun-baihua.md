# 大运流年（白话）

> 来源：《滴天髓·岁运》《贞元》；《渊海子平·继善篇》太岁诸句；《三命通会》卷二论大运、小运、太岁、岁运；
> 《五行精纪》卷三十三至三十四（论大运、小运、二运、太岁、晦数、岁运）；《千里命稿》论行运。
> 起运、排运的计算规则见 `references/tables/dayun-rules.md`，脚本已自动计算。

## 一、基本规则
- **排法**：阳年男、阴年女顺排；阴年男、阳年女逆排；从月柱起，每步十年。
- **起运**：出生到下一个（顺）或上一个（逆）节的天数，三天折一年（脚本精确到年月日）。
- **起运前**：古法看小运，现代多以月柱论童年。
- **天干与地支**：一般说天干管前五年、地支管后五年，但地支力量大于天干，整个十年都要看地支。
- **大运与原局一体看**：大运干支进入原局，等于原局多了一柱，重新看旺衰、格局、用神是否得力。

## 二、大运吉凶判断
1. 大运五行是否为喜用神：喜则吉，忌则凶。
2. 大运与原局的冲合（脚本 `dayun[].relations`）：
   - 冲提纲（月令）：环境大变动，格局受影响。
   - 冲日支：配偶、居所、身体变化。
   - 合去喜用：好运打折；合去忌神：转吉。
   - 三合三会成局：五行力量大增，看成的是喜是忌。
3. 大运是否“盖头截脚”：天干克地支（如庚寅）或地支克天干（如甲申），作用互相抵消。
4. 专旺、从格：顺其气势则吉，逆之则凶（如曲直格行金运大忌）。

## 三、流年
- 《滴天髓》：“休囚系乎运，尤系乎岁，战冲视孰降，和好视孰切。”流年作用更直接。
- 《继善篇》：“太岁乃众杀之主，入命未必为灾，若遇战斗之乡，必主刑于本命。岁伤日干，有祸必轻；日犯岁君，灾殃必重。五行有救，其年反必为财。”
- 关注：
  - **岁运并临**（流年干支与大运相同）：力量加倍，吉凶都显著。
  - **岁运相冲**：动荡、变化。
  - **伏吟**（流年与原局某柱相同）：重复、烦闷、旧事重提。
  - **反吟**（流年冲原局某柱干支）：变动、离别。
  - 流年冲日支：婚姻、搬家、健康；冲月柱：工作、父母；冲年柱：长辈、祖业；冲时柱：子女、下属。
  - 流年引出用神或配偶星、财星、官星：对应事件的应期。

## 四、应期常用法
| 事件 | 常见应期信号 |
|---|---|
| 婚恋 | 男命财星、女命官星透出或到位；流年合日支、冲日支；桃花年 |
| 升迁 | 官星（身旺）或印星（身弱）到位；官印相生之年 |
| 发财 | 财星为喜到位；食伤生财；财库被冲开 |
| 搬迁、出行 | 驿马年；冲日支、冲月支 |
| 破财 | 比劫为忌而旺；财星被冲克 |
| 是非官司 | 伤官见官、七杀无制、羊刃冲合 |
| 健康 | 忌神旺而攻某五行；冲刑叠见 |
| 学业考试 | 印星、文昌、官印相生；食伤配印 |

## 五、古法补充（《五行精纪》岁运）
- 古法以年柱（本命）为主，看行年大小二运与本命纳音生克：运生命吉深，命生运吉浅；运克命凶多，命克运凶少。
- 丧门（命前二辰）、吊客（命后二辰）、破宅、会神、勾绞、浴盆等，用于流年事件的辅助判断。原文 `grep -n "破宅" references/classics/wuxing-jingji.md`。

## 六、贞元（人生阶段）
- 年为元、月为亨、日为利、时为贞：年月吉前半生好，日时吉后半生好。
- 大运每十五年一段，前两段吉早发，后两段吉晚成。

## 七、写法示例
> 当前乙卯大运（2017—2026），乙木正财合日干庚、卯木冲年支酉：财星当令而身稍弱，多机会但需借力。
> 2026 丙午年：丙火七杀合时干辛，午火与月日两午自刑，岁运木火相生攻身——工作压力大，宜以印化杀，
> 留意睡眠与心血管（以体检为准）。依《滴天髓》“战冲视孰降”，丙火七杀旺而庚金失令，宜守不宜攻。
