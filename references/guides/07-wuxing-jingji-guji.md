## 一、古法与子平法的区别
| | 唐宋古法（禄命法） | 子平法 |
|---|---|---|
| 命主 | 年柱（本命）、纳音 | 日干 |
| 核心工具 | 纳音五行生克、禄马贵人、神煞、胎月日时 | 十神、月令格局、旺衰、调候 |
| 代表书 | 《五行精纪》《珞琭子》《李虚中命书》《兰台妙选》 | 《渊海子平》《子平真诠》《滴天髓》《穷通宝鉴》 |
| 本 skill 用法 | 补充：本命纳音、神煞、取象 | 主体：格局、旺衰、用神 |

《五行精纪》三十四卷的结构见该文件开头卷目。最常用的是：卷一卷二（纳音）、卷十三至二十七（吉神凶神）、卷二十九至三十一（男女命、六亲、性情、疾病寿夭）、卷三十三三十四（运限岁运）。

## 二、纳音怎么用（古法要点）
1. 年柱纳音为本命，日柱、胎元、月时纳音与之相生为吉，相克为凶。
2. 纳音“喜克”与“忌克”因各自性质不同：如海中金、剑锋金不怕火（火能成器），沙中金、金箔金怕火。
3. 纳音也看生旺死绝：自生、自旺、临官者有力，自病、自死、自绝者无力，需扶助。
4. 子平法中，纳音只作参考说明，不改变用神判断。

## 四、古法常用断法（白话摘要）
- **纳音相生**：年纳音生日纳音，长辈庇荫；日纳音生年纳音，孝顺付出。
- **胎中受克**：《兰台妙选》“子归母腹”：生时为长生胎宫且纳音生本命为吉，反之“胎中受克，非贫则夭”（古说，仅参考）。
- **禄马贵人**：以年干查禄、贵人，以年支查驿马；禄马同乡（如壬午）主富贵。
- **运限**：行年大小运与本命纳音相生比合则吉，战克则凶；见丧门、吊客、勾绞须防孝服是非。
