# 《千里命稿》方法要点（白话归纳）

> 韦千里（1911—1988）著，民国时期的白话命理教科书，本书仍受版权保护，故**本 skill 不收录原文**，
> 只用本 skill 自己的话归纳其方法体系，供论命流程使用。用户手头有原书时可对照阅读。

## 一、全书脉络（依扫描本抽查所见）
1. **起例问答**：用问答体讲天干地支、六十甲子、年柱以立春为界、月柱以节为界、日上起时（五鼠遁）、年上起月（五虎遁）、大运顺逆与起运岁数的算法。——本 skill 由脚本完成这些计算。
2. **地支逐一详解**：每个地支的方位、月令、藏干、合（六合、三合、方合）、刑、冲、害，并举例说明某支在不同日干下的作用。
3. **月令取格**：逐个日干、逐个月令列出“月令某支、透出某干即为某格；未透则如何”的规则，并注明“透亦可取、不透亦可取”等细节。
4. **生克制化**：分析天干之间、地支之间、干支之间生克的力量差别，如“相邻者力大、隔位者力小”“一克一、两克一的强弱”等。
5. **用神与行运**：以日主强弱为纲，取扶抑；兼顾调候、通关；依用神断行运吉凶。
6. **实例**：大量近现代人物命造，示范从排盘到断语的全过程。
7. **附录**：民国以来的万年历。

## 二、方法要点（本 skill 归纳）

### 1. 取格以月令为先
- 月令藏干透出天干的，以透出者定格；多个透出时取当令或最有力者。
- 月令本气为日主之比劫（禄、刃），另取透出之财官食伤为格。
- 这与《子平真诠》一脉相承，也是本 skill 取格的默认方法（详见 `03-geju-daquan.md`）。

### 2. 生克力量讲“距离”和“数量”
- 紧贴的干支作用大，隔一柱作用减，隔两柱更弱；年与时相距最远。
- 天干克天干，若被克者有地支通根，伤害减轻；若克者无根，克力虚浮。
- 一对一相克，力量看旺衰；以多克少，少者受伤重。
- 地支冲：旺冲衰则衰者拔，衰冲旺则旺者发（与《滴天髓》一致）。

### 3. 强弱判断讲“月令、通根、帮扶”三项
- 先看月令，再看地支通根（本气根重于余气根），最后看天干帮扶；同时计算克、泄、耗。
- 日主强则喜克泄耗（官杀、食伤、财），日主弱则喜生扶（印、比劫）。

### 4. 用神的几种取法（与本 skill 用神五法一致）
扶抑为主；冬夏调候；两强相战取通关；有病取药；一行专旺或日主无根则顺其势（专旺、从化）。

### 5. 断六亲、事业、行运
- 星宫合参：十神定人，柱位定宫。
- 事业以用神五行与格局类型定方向。
- 行运以大运干支对用神的生克为主，流年为引动。

### 6. 写断语的风格
- 用白话、讲理由、举实例、避免神煞恐吓——本 skill 的解读风格也以此为准。
