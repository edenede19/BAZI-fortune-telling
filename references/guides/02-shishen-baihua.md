# 十神白话大全

> 综合《渊海子平》卷二十神诸论、《三命通会》卷五《论古人立印食官财名义》及诸论、《滴天髓》官杀/伤官章、
> 《千里命稿》论十神诸节的观点，由本 skill 用白话整理。原文可在 classics 目录中 grep。

## 一、十神怎么来

以日干为“我”，看其他天干（含地支藏干）与我的五行生克及阴阳异同：

| 关系 | 同性（阳见阳/阴见阴） | 异性 |
|---|---|---|
| 同我 | 比肩 | 劫财（阳干的劫财又称“败财”，羊刃即阳干劫财之禄地） |
| 我生 | 食神 | 伤官 |
| 我克 | 偏财 | 正财 |
| 克我 | 七杀（偏官） | 正官 |
| 生我 | 偏印（枭神、倒食） | 正印（印绶） |

古人的立名之意（《三命通会·论古人立印食官财名义》大意）：克我者如国法管束，异性相克为“正官”有礼有节；同性相克为“七杀”无情。生我者如父母庇护，名“印绶”。我生者泄我之气，同性而有情名“食神”，异性而伤我之官名“伤官”。我克者为我所役使之财，异性如夫妻相配为“正财”，同性如众人之财为“偏财”。

## 二、逐一白话

### 正官
- **象义**：管束、名誉、职位、规矩、法律、上司；男命为女儿（一说子女），女命为丈夫。
- **喜**：日主健旺能任官；财星生官（财官相生）；印星护官化官（官印相生）；官星清纯只一位，坐月令最真。
- **忌**：伤官克官（伤官见官，为祸百端）；刑冲破害；官杀混杂；官星太多（官多变杀）；日主衰弱（衰则变官为鬼）。
- **性情**：端正守礼、有责任心、循规蹈矩；太多则拘谨怕事。
- **《渊海》要语**：正官乃贵气之物，大忌刑冲破害；须看年时上别有何格作福去处方可断其吉凶。
- **行运**：喜财运、印运、官运（身旺时）；忌伤官运、冲官运。

### 七杀（偏官）
- **象义**：权威、压力、竞争、魄力、武职、执法、小人、病灾；男命为儿子，女命为情人或丈夫（无正官时）。
- **喜**：身旺敌杀；有食神制杀（食神制杀最贵）；有印化杀（杀印相生）；有羊刃合杀（杀刃格）。
- **忌**：身弱杀重无制（杀重身轻，终身有损）；财来生杀而身弱；制伏太过（尽法无民，反为贫儒）。
- **性情**：有制者果断有魄力、敢作敢当；无制者急躁、刚愎、易招是非伤灾。
- **《渊海》比喻**：偏官如抱虎而眠，虽借权势，稍失关防必为噬脐——有制伏才可用。
- **行运**：身弱喜印、比劫运；身强杀浅喜财杀运；有制则忌再行制运，无制则喜制运。

### 正印（印绶）
- **象义**：母亲、学业、文凭、名誉、庇护、贵人、房产、宗教心、福寿。
- **喜**：身弱得印生扶；官杀生印（官印双全）；印透而有根。
- **忌**：财星破印（贪财坏印）；印太多身太旺（母慈灭子，反使食伤受克、懒散）。
- **性情**：仁慈、宽厚、好学、重精神，依赖心强。
- **《渊海》要语**：印绶畏财，主人多智虑，兼丰厚；有官无印即非真官，有印无官反成其福。
- **行运**：身弱喜官印运；身旺印多喜财运破印。

### 偏印（枭神、倒食）
- **象义**：偏门学问、宗教玄学、艺术、医卜、特殊技能、继母；与食神相遇称“倒食”，夺我福禄。
- **喜**：身弱时与正印同论；有偏财制枭；七杀旺时偏印化杀。
- **忌**：遇食神而无财制（枭神夺食），主福薄、多病、子女缘薄。
- **性情**：敏锐、孤僻、多疑，有独特见解，做事有始无终。
- **《渊海·论倒食》**：用食神者大忌见之；作事进退悔懒，有始无终，财源屡成屡败。

### 正财
- **象义**：工资收入、稳定财富、勤俭、妻子（男命）、父亲（一说偏财为父）。
- **喜**：身旺能任财；食伤生财；财能生官（财旺生官，富而且贵）。
- **忌**：比劫夺财；财多身弱（富屋贫人）；身弱又行财运。
- **性情**：踏实、勤俭、重信用、务实，有时吝啬保守。
- **行运**：身旺喜财运、食伤运；身弱喜比劫、印运。

### 偏财
- **象义**：横财、投资、生意、流动资金、父亲、情人（男命）；“众人之财”。
- **喜**：身强财旺；有官星护财；时上偏财一位清纯。
- **忌**：比劫分夺（时上偏财怕逢兄弟）；身弱财多。
- **性情**：慷慨豪爽、善交际、重义轻财、风流。

### 食神
- **象义**：福禄、口福、才艺、表达、享受、子女（女命）、寿元。
- **喜**：身旺食神生财；食神制杀；食神一位清纯有力。
- **忌**：偏印夺食（倒食）；身弱食多泄气过度；官星混见（食官不宜同用）。
- **性情**：温和宽厚、乐观、有口福、体胖、才艺出众。
- **《渊海·论食神》**：带此者主人财厚食丰，腹量宽洪，肌体肥大，优游自足，有子息，有寿考。

### 伤官
- **象义**：才华、创意、口才、叛逆、技艺、子女（女命）；伤克正官，女命主婚姻波折。
- **喜**：伤官伤尽（原局无官，岁运亦不见官）；身旺伤官生财；身弱伤官佩印；伤官驾杀（伤官制七杀）。
- **忌**：伤官见官（尤其身弱又无印）；伤官旺而无财无印，聪明而不得志。
- **性情**：聪明傲物、多才多艺、好胜、恃才傲上，感情丰富。
- **《渊海·论伤官》**：伤官者其验如神，伤官务要伤尽，伤之不尽，官来乘旺，其祸不可胜言。
- **《滴天髓》补充**：伤官用印，无财不宜见财；伤官用财，无印不宜见印——须视具体格局。

### 比肩
- **象义**：兄弟姐妹、朋友、同事、合伙人、竞争者、自我。
- **喜**：日主弱时帮身；财多身弱时比肩分担（化富屋贫人为能任财）。
- **忌**：日主已旺再见比肩；与财星并见而争财。
- **性情**：独立、自尊、固执、讲义气。

### 劫财
- **象义**：争夺、破财、冒险、兄弟朋友（多主拖累）；男命克妻（克正财）。
- **喜**：身弱财旺时帮身；七杀旺时合杀（阳刃劫财合杀）。
- **忌**：身旺再见劫财，破财、克妻、是非；行劫财运多耗散。
- **性情**：积极、冲动、好胜，行事大胆，但易感情用事。
- **《渊海·论劫财》**：男命见劫财多克妻，女命见伤官多克夫。

### 羊刃（阳干劫财之禄地：甲卯、丙戊午、庚酉、壬子）
- **象义**：刚强、兵刑、血光、权威；武职、外科、执法者多见。
- **喜**：身弱帮身；有七杀相制（杀刃两全，主威权）；有印化。
- **忌**：刃旺无杀制；岁运冲刃、合刃（阳刃冲合岁君，勃然祸至）。

## 三、十神组合常用口诀（白话）

| 组合 | 白话含义 |
|---|---|
| 财官印全 | 财生官、官生印、印生身，富贵俱全（须身旺无破） |
| 官印相生 | 名誉地位稳，适合公职、学术 |
| 杀印相生 | 压力化为权力，有魄力的管理者 |
| 食神制杀 | 才能驾驭压力，主威权，最贵格之一 |
| 伤官配印 | 才华有约束，文人学者、专业人士 |
| 伤官生财 | 以才艺技术求财，经商、创作有成 |
| 食伤生财 | 能赚钱，财路畅通（“财气通门户”） |
| 财多身弱 | 富屋贫人，有财不能享，宜比劫印运 |
| 官杀混杂 | 是非多、职业变动；去一留一则清 |
| 伤官见官 | 与上司、规则冲突，女命婚姻多波折 |
| 枭神夺食 | 福禄受阻，健康、子女需注意 |
| 比劫夺财 | 破财、合伙不利，男命婚姻不顺 |
| 印多身旺 | 依赖、懒散，宜财运破印、食伤泄秀 |
| 财星坏印 | 为财失名、母亲健康，学业受干扰 |

## 四、十神与六亲（通行说法）

| 十神 | 男命 | 女命 |
|---|---|---|
| 正印 | 母亲 | 母亲 |
| 偏印 | 继母、祖父 | 继母、祖父 |
| 正财 | 妻子 | 父亲（一说） |
| 偏财 | 父亲、情人 | 父亲 |
| 正官 | 女儿 | 丈夫 |
| 七杀 | 儿子 | 情人、丈夫（无正官时） |
| 食神 | 孙辈、女婿 | 女儿 |
| 伤官 | 祖母、外孙 | 儿子 |
| 比肩 | 兄弟 | 姐妹 |
| 劫财 | 姐妹 | 兄弟 |

宫位配合：年柱祖上、月柱父母兄弟、日支配偶、时柱子女。星（十神）与宫（柱位）合参，详见 `10-liuqin-xingqing-jibing.md`。
